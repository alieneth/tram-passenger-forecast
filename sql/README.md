# sql — витрина и анализ данных (Дмитрий)

Что здесь будет:

- логическая модель данных и DDL таблиц;
- витрина «маршрут × час × факторы» для модели и API;
- запросы первичного анализа: отказы валидации, дубли, пропущенные часы и дни, выбросы;
- сверка `boardings` с labels.

Правила оформления (раздел 11.6 в `/CLAUDE.md`):

- ключевые слова ЗАГЛАВНЫМИ, имена таблиц и полей — `snake_case`;
- каждый столбец и условие — с новой строки, понятные алиасы;
- один запрос — один файл `NN_nazvanie.sql` с комментарием в начале: что считает и зачем.
