# Выбранный сабмит: WAPE-score 0,88724

Платформенная проверка: исходный профиль с нулевыми ночными часами — **0,88518**;
тот же прогноз с ограничениями движения №7 и №50 — **0,88724**.
Измеренный прирост: **+0,00206**. Результаты получены из ответа платформы;
запись и хэши: [platform_scores.json](reports/platform_diagnostic/platform_scores.json).

## Модель

98% сезонного медианного профиля + 2% суммы обычного медианного профиля и
остатка LightGBM (150 деревьев, objective=regression_l1). История — январь–октябрь 2025.
Профили учитывают маршрут, час, день недели, летний период и производственный календарь.
Признаки включают исторические агрегаты, тренд, климатологию 2022–2024,
события, исторический риск ДТП, приближённый профиль трафика и показатель OSM.
Наличие признака не означает подтверждённый положительный эффект каждого источника.
CatBoost и нейросеть в выбранный сабмит не входят.

На 2, 8 и 9 ноября №50 обнуляется, №7 получает множитель около 0,57436.
Основания и ограничения переноса: [отчёт экспериментов](ALTERNATIVE_MODELS_REPORT.md).
Маршрут 5 и часы 01–04 обнулены. Все прогнозы — неотрицательные целые числа.
Формат: route;date;hour;prediction, 14 640 строк, ноябрь–декабрь 2025.

Это постобработка сохранённого старого прогноза, без переобучения: исключение
ночных наблюдений из обучения этой старой модели не обеспечивается.
Объявление о возобновлении движения опубликовано после начала горизонта;
использование этого правила является ретроспективным экспериментом.

## Файлы и воспроизведение

Передаваемый отдельно файл: `submission_new.csv` (исходное имя `03_champion_both.csv`).
SHA256: `c725598b623ae64d7f8979a11c208efcb51f4ae6919c8c2caa40a712ec4b11bd`.
Веса опубликованы отдельным GitHub Release; артефакты и сабмиты не включаются в Git по правилам проекта.

Из корня репозитория, Python 3.11+ (проверено на Python 3.12):

```bash
python -m pip install -r ml/requirements.txt
python -m ml.reproduce_submission --download
```

Результат: `ml/artifacts/submission_new.csv` и файл проверки рядом с ним.
Команда загружает `bundle.joblib` из [GitHub Release](https://github.com/alieneth/tram-passenger-forecast/releases/tag/ml-platform-0.88724-v2),
проверяет SHA256 весов по `ml/champion/manifest.json`, рассчитывает прогноз
и применяет ограничения движения. Готовый CSV не используется как вход модели.
Внутри `bundle.joblib` сохранены деревья, исторические профили и внешние признаки;
исходный датасет для этого инференса не нужен. Загружать joblib следует только
из доверенного источника с проверкой манифеста.

После загрузки запуск полностью офлайн:

```bash
python -m ml.reproduce_submission
python -m pytest ml/tests/test_reproduce_submission.py -q -p no:cacheprovider
```

Интеграционный тест запрещает сеть и чтение любых CSV во время инференса:
из модели получаются все 14 640 строк с точным SHA256 платформенного файла.
CRLF зафиксирован явно, чтобы байты CSV совпадали на Windows и Linux.
Score 0,88724 сообщён платформой; скрытые метки отсутствуют, локально этот score
не пересчитывается. Проверяется точное воспроизведение отправленного файла,
а не идентичность повторного обучения модели с нуля.

Для независимой проверки отдельных поправок сохранён дополнительный инструмент:

```bash
python -m ml.experiments.platform_ablation --champion PATH_TO_ORIGINAL_SUBMISSION --output ml/artifacts/platform_ablation
```

Параметры поправок: `ml/reports/alternatives/selection.json`.

Пакет PostgreSQL для этого выбранного CSV ещё не сформирован и в БД не записан.
Почасовые/суточные выгрузки альтернативного CatBoost относятся к другой модели;
не следует выдавать их за пакет выбранного сабмита.
