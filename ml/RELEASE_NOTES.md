Сохранённая модель для воспроизведения сабмита с платформенным WAPE-score **0,88724**.

Веса включают LightGBM, исторические профили и замороженные внешние признаки.
Поправки на ограничения движения №7 и №50 применяются кодом из соответствующего тега.
Датасет и готовый CSV не нужны для инференса.

После checkout тега `ml-platform-0.88724-v2`, из корня репозитория:

```bash
python -m pip install -r ml/requirements.txt
python -m ml.reproduce_submission --download
```

Выход: `ml/artifacts/submission_new.csv`, 14 640 строк.
SHA256: `c725598b623ae64d7f8979a11c208efcb51f4ae6919c8c2caa40a712ec4b11bd`.

Проверено локальное воспроизведение из весов без чтения CSV и без сети.
Публикующий workflow проверяет контрольную сумму весов; он не переобучает модель.
Score сообщён платформой, скрытые метки локально недоступны.

Используется ретроспективная информация о возобновлении движения.
Предел применимости этого фиксированного выпуска — ноябрь–декабрь 2025.
