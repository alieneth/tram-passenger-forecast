## Файлы

- `ml/artifacts/final_release/test_submission.csv` — единственный выбранный сабмит, копия `oracle_delivery/restored/test_submission.csv`.
- `ml/artifacts/final_release/bundle.joblib` — обученная модель, профили, внешние признаки и калибровка интервалов.
- `ml/artifacts/final_release/forecast.csv` — пакет для PostgreSQL: 13 176 почасовых и 549 суточных строк, девять маршрутов.
- `ml/artifacts/final_release/model_version.json` — метаданные версии; `manifest.json` — SHA256 файлов.
- `ml/artifacts/final_release/forecast_week_example.csv` — пример недели по дням; `forecast_daily.csv` — весь двухмесячный период по дням.

Артефакты моделей, CSV для платформы и внешние данные остаются вне Git по правилам репозитория.
В коммит входят код, тесты, отчёты, выполненные EDA-ноутбуки и графики. Локальный архив для передачи артефактов: `ml/artifacts/ml_final_release.zip`.

SHA256 выбранного сабмита: `89a710f9f2f22a8f93287d886158d34d236c3a6501f63e28967471ed4e559ff5`.
Формат: `route;date;hour;prediction`, ровно 14 640 строк, 2025-11-01 — 2025-12-31.
Маршрут 5 и часы 01–04 равны нулю; час 05 сохранён; прогнозы неотрицательные целые.

## Подтверждённые результаты

- Погода и подбор параметров: WAPE-score **0,891932 → 0,892502**, проверка сентября–октября.
- При одинаковых параметрах фактическая погода добавила **0,000041** WAPE-score.
- Восстановление: **0,895848 → 0,896449**, отдельная проверка октября при обучении по сентябрь включительно.

Эти две проверки имеют разные интервалы и не складываются. Для финального варианта с восстановлением нельзя выдавать октябрьский score за результат сентября–октября или платформы.
Проверочные labels не восстанавливались; изменялась только обучающая история. Позднее установлено совпадение четырёх провалов с отменами движения; восстановление не используется в выбранном сабмите.

## Ограничения

Пакет намеренно использует будущую фактическую погоду (ERA5), а не прогноз, выпущенный до целевых дат.
Он предназначен для разрешённого ретроспективного эксперимента на ноябре–декабре 2025, а не для реального прогноза на новые даты.
Варианты с дополнительными фактическими ДТП и событиями были проверены, но лучший результат не улучшили.
Рабочий режим с климатологией сохранён в `ml.qna`; прежний платформенный эталон — в `ml.champion`.
Годовой горизонт в этом экспериментальном пакете отсутствует. Запись в PostgreSQL и активация новой версии ещё не выполнялись.

## Использование пакета

После распаковки артефактов в `ml/artifacts/final_release/`, из корня репозитория:

```python
import joblib
from ml.experiments.oracle_delivery import forecast

bundle = joblib.load("ml/artifacts/final_release/bundle.joblib")
day = forecast(bundle, "2025-11-14", "2025-11-14", "day")
week = forecast(bundle, "2025-11-10", "2025-11-16", "week")
month = forecast(bundle, "2025-11-01", "2025-11-30", "month")
```

Загружать joblib следует только из доверенного пакета после проверки SHA256 по манифесту.
Для недели и месяца возвращаются суточные строки с `hour=NULL`, `horizon=month`, как требует DDL.
Сеть для инференса готового пакета не нужна. Полное повторение обучения: [ORACLE_EXPERIMENT.md](ORACLE_EXPERIMENT.md).
