# ml — модель прогноза (Ярослав)

Python 3.11+, форматирование и линтер — ruff (см. раздел 11 в `/CLAUDE.md`).

Что здесь будет:

- расчёт `boardings` из валидаций и сверка с labels;
- признаки: календарь, лаги, трамваи на линии, погода, окружение остановок;
- базовая модель (среднее за тот же час и день недели) и LightGBM;
- прогноз маршрута 5 по аналогам;
- файл сабмита `route;date;hour;prediction`;
- пакетный пересчёт прогнозов в таблицу БД, из которой читает Java-API.

Артефакты моделей — в `ml/artifacts/` (в git не кладём).
