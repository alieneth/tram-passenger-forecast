# Анализ модели, давшей около 0,88 на платформе

Это анализ сохранённой и повторно обученной модели, а не подбор объяснений к другому алгоритму. Проверка: [verification.json](reports/champion/verification.json), [ошибки по маршрутам](reports/champion/validation_by_route.csv), [важности признаков](reports/champion/feature_importance.csv).

## Как получается прогноз

Выпуск содержит обученную гибридную модель:

`prediction = round(clip(0.98 * seasonal_profile + 0.02 * (median_profile + LightGBM(features)), 0))`.

После этого применяется сохранённая маска закрытых часов/маршрутов. LightGBM обучается на остатке `boardings - median_profile` с `objective=regression_l1`, 150 деревьев. Сезонный профиль — медианы посадок по маршруту, часу, дню недели и признаку лета с поправкой официального типа дня. Доля CatBoost в финальном прогнозе равна нулю, хотя код сравнения и обученный компонент сохранены.

Это не один чистый LightGBM и не среднее погоды, выданное за число пассажиров. Заменить смесь чистым бустингом и назвать её прежней моделью со score 0,88 нельзя. Сохраняем именно проверенную смесь.

## Два разных вида исторических признаков

1. **История пассажиров 2025:** среднее и медиана route × час × день недели, профиль выходного дня, сезонный профиль, доля часа, относительный тренд. Профили также передаются в LightGBM. Пассажирских данных 2022–2024 в предоставленном наборе нет.
2. **Погода 2022–2024 из Open-Meteo:** месячные средние температуры, осадков, снега и ветра. Это только входные признаки LightGBM. Они не являются целевой переменной, прогнозом посадок или фактической погодой 2025 года.

Для ноября температура-признак −0,226°C, для декабря −4,532°C. Остальные значения — [weather_features.csv](reports/champion/weather_features.csv). Признаки постоянны внутри месяца и не предсказывают конкретный снегопад. Это климатический прокси по трём годам, а не официальная климатическая норма за 30 лет.

В финальном LightGBM реально используются температура (55 разбиений), ветер (49), осадки (11). Снег не выбран (0). Количество разбиений подтверждает участие в деревьях, но само по себе не доказывает пользу на независимом тесте.

## Воспроизведение качества

| Проверка на известных 9 маршрутах сентября–октября | MAE | WAPE-score |
|---|---:|---:|
| Средний профиль route × день недели × час | 133,298837 | 0,862296 |
| Выбранная гибридная модель | 104,485428 | 0,892061 |

MAE ниже baseline примерно на 21,6%. Самые слабые маршруты по относительной ошибке: №50 (score 0,762857), №25 (0,833990), №7 (0,835517). Аномальный нулевой день №50 не удалён из оценки. Для №5 нет наблюдений: нулевой факт для оценки качества не выдумывается.

Оценка сентября–октября диагностическая: этот период просматривался при разработке. Около 0,88 на скрытой платформе — сообщение пользователя о старом файле, не новая загрузка и не независимо полученный нами результат.

Повторное обучение с сохранённым локальным кэшем воспроизвело score **0,8920614645158826** и все **14 640** значений старого сабмита. SHA256 полученного Windows CSV: `0fcac1502fa3423e51d784bf731a2526e18f5b3d2d58c21d7776be06eee6942f`.

## Внешние источники и ограничения

Подключены Open-Meteo, XMLCalendar, OSM, KudaGo, исторический архив ДТП. Отчёт об эффекте каждого и ограничения доступности на дату прогноза — [CRITERIA_REPORT.md](CRITERIA_REPORT.md). Четыре положительных эффекта не подтверждены: наличие источника не подменяет абляцию.

Полный EDA — [DATA_QUALITY.md](DATA_QUALITY.md). Пропуски pass_route нельзя считать отсутствием пересадки; place_id не является остановкой; хвосты raw разделены по времени операции; аномалии не удалены догадками. Проверенная модель учится по labels, поэтому эти результаты EDA не выдаются за новые признаки чемпиона.

## Повтор анализа

После обучения из README:

```bash
python -m ml.champion.analyze --retrained ml/artifacts/champion_retrained
```

Команда проверяет равенство нового сабмита эталону, даты погодных запросов 2022–2024, состав признаков и ошибки по маршрутам. Если обучение на обновлённых внешних источниках изменило прогнозы, проверка завершится ошибкой, а не объявит новую модель прежним победителем.
