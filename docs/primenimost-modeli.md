# Область определения и адаптации модели

Документ отвечает на вопросы: где модель прогноза даёт надёжный результат, от каких данных она зависит,
где её применять нельзя и что нужно, чтобы перенести её на новые маршруты и периоды.

## Что прогнозирует модель

| Параметр | Значение |
|---|---|
| Целевая величина | Число входов пассажиров (успешных валидаций, `validation_result = 1`) на маршруте за час |
| Маршруты | 9 трамвайных маршрутов: 1, 7, 11, 12, 17, 25, 26, 28, 50. Маршрут 5 исключён организаторами (проблемы при выгрузке данных) — прогноз 0 |
| Горизонты | День — по часам; неделя и месяц — по дням (сумма почасового прогноза). Год — не заявлен |
| Период прогноза | Ноябрь–декабрь 2025 (61 день) — до двух месяцев после окончания данных |
| Обучающие данные | Валидации за январь–октябрь 2025: 62,4 млн строк, 9 маршрутов |
| Алгоритм | Градиентный бустинг LightGBM (L1-регрессия) по признакам календаря, погоды, истории потока и внешних факторов |

## Качество

| Показатель | Значение | Где измерено |
|---|---|---|
| WAPE-score на платформе организаторов | ≈ 0,89 | Ноябрь–декабрь 2025, автоматическая проверка |
| WAPE-score на проверочном периоде | 0,892 | Сентябрь–октябрь 2025 (модель обучена на январе–августе) |
| MAE на проверочном периоде | 104,5 пассажира в час | Сентябрь–октябрь 2025 |
| Базовая модель (средний профиль) | WAPE-score 0,862, MAE 133,3 | Тот же период |
| Порог организаторов (baseline) | 0,48 | — |

WAPE-score = 1 − Σ|факт − прогноз| / Σ факт. Сентябрь–октябрь многократно использовался при подборе модели,
поэтому оценка на нём может быть немного оптимистичной; независимая проверка — результат на платформе.

## Область определения — где модель валидна

Модель даёт надёжный прогноз, если выполнены все условия:

1. **Маршрут из обучающего набора** — один из 9 маршрутов с историей валидаций.
2. **Обычный режим работы маршрута** — без изменения трассы, длительных ремонтов путей и перебоев с оборудованием валидации.
3. **Рабочие часы трамваев** — примерно с 05:30 до 01:00. Ночные валидации — технологические (проверка оборудования), в обучении не используются, ночной прогноз — 0.
4. **Горизонт до двух месяцев** от конца обучающих данных.
5. **Календарь известен** — праздники, переносы выходных и каникулы на прогнозный период загружены.
6. **Внешние данные в пределах наблюдавшихся значений** — погода и события не экстремальные по сравнению с январём–октябрём.

## Где модель применять нельзя или с осторожностью

| Ситуация | Почему | Что происходит |
|---|---|---|
| Новый маршрут без истории | Нет данных для обучения | Прогноз не строится (как для маршрута 5) |
| Изменение трассы, ремонт путей, перекрытие | Модель учила обычный режим | Прогноз завышен |
| Сбой валидаторов на маршруте | В факте «провал», которого нет в реальности | Прогноз корректен, но сравнение с фактом неверно |
| Горизонт больше двух месяцев, прогноз на год | В данных 10 месяцев, ноября–декабря прошлых лет нет — годовая сезонность видна только частично | Точность падает, нужна осторожность |
| Экстремальные события (крупные аварии, аномальная погода) | Редки в обучении | Эффект недооценивается |
| Ночные часы | Технологические валидации | Прогноз 0 |
| Отдельная остановка | Остановки входа в данных нет | Прогноз по остановке — только оценка (доля от маршрута) |

## Зависимость от внешних данных

| Источник | Что даёт модели | Ссылка | Эффект на проверке |
|---|---|---|---|
| Производственный календарь | Праздники, переносы выходных, предпраздничные дни | https://xmlcalendar.ru/data/ru/2025/calendar.json | Положительный; заметно помог на весенних переносах |
| Погода | Средняя температура, осадки, снег, ветер (климатическая норма 2022–2024 по месяцам) | https://open-meteo.com/en/docs/historical-weather-api | Небольшой положительный |
| Дорожная сеть (прокси трафика) | Плотность дорог рядом с маршрутом, эвристика часов пик | https://overpass-api.de/api/interpreter (OpenStreetMap) | Не подтверждён |
| События | Число мероприятий, короткие события | https://kudago.com/public-api/v1.4/events/ | Не подтверждён |
| ДТП | Историческая частота ДТП по месяцу, дню недели и часу | https://dtp-stat.ru/opendata/ | Не подтверждён |

Если внешний источник недоступен, модель использует последние сохранённые данные (кэш); прогноз строится,
но без свежего значения фактора.

## Область адаптации — как перенести модель

| Задача | Что нужно | Что делать |
|---|---|---|
| **Новый период** (например, 2026 год) | Свежие валидации, календарь на новый год, погода | Переобучить модель на новых данных, записать новую версию в `model_version` и сделать её активной |
| **Новый маршрут с историей** | Не меньше нескольких месяцев валидаций, запись в справочнике | Добавить маршрут в справочник, переобучить модель |
| **Новый маршрут без истории** | Трасса и остановки с координатами, похожие маршруты с историей (район, пересадки на метро, длина) | Прогноз по аналогам: профиль похожих маршрутов с поправкой; точность ниже, коридор шире |
| **Прогноз по остановкам** | Полное расписание и наряды (привязка валидаций к остановке по номеру выхода и времени) | Распределить поток маршрута по остановкам, обучить модель на уровне остановок |
| **Загрузка вагона в %** | Выходы пассажиров (например, валидации метро с тем же хэшем карты) и вместимость вагонов | Оценка выходов через пересадки, расчёт наполняемости по участкам |
| **Другой вид транспорта** (автобус, электробус) | Валидации и справочники в том же формате | Тот же пайплайн, переобучение модели |

## Итог

Модель валидна для 9 трамвайных маршрутов с историей, в обычном режиме их работы, на горизонте до двух
месяцев, при известном календаре. Для новых маршрутов, остановок и горизонта «год» нужны дополнительные
данные — они перечислены в разделе «Область адаптации».
