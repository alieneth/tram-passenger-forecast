# Материалы для жюри

Команда «Пацаны из Стрешнево», трек «ИИ-прогноз загрузки трамвайных маршрутов».
Этот файл — оглавление: где в репозитории лежит каждый обязательный артефакт и что в нём смотреть.

**Коротко о решении.** Сервис прогнозирует число входов пассажиров по 9 трамвайным маршрутам на день
(по часам), неделю и месяц (по дням) и предлагает диспетчеру перераспределение трамваев.
Прогноз считается заранее в Python и хранится в PostgreSQL, API на Java только читает готовое,
интерфейс — React. Всё поднимается одной командой `docker compose up -d`.

| Показатель | Значение |
|---|---|
| WAPE-score на платформе организаторов | **0,88724** |
| Нагрузочный тест API (k6, до 300 пользователей) | **743 RPS, p95 300 мс** |
| Данные для обучения | 62,4 млн валидаций, январь–октябрь 2025 |
| Запуск | `docker compose up -d`, интерфейс — http://localhost:3000 |

Дополнительные возможности сверх обязательного прогноза на день:

- горизонты неделя и месяц (по дням), коридор уверенности прогноза;
- карта маршрутов и «проигрывание» дня по часам;
- «Что если» — поправочные коэффициенты с пересчётом прогноза;
- предложения диспетчеру по перераспределению трамваев;
- экран «Качество модели» — ошибка модели против базовой;
- выгрузка в CSV, XLSX и формате сабмита;
- приём потока валидаций `POST /validations` с авторизацией по токену;
- тёмная тема интерфейса для диспетчерской.
