# Инструкция для жюри

Сервис прогноза пассажиропотока трамваев. Ниже — как запустить его за несколько минут и что посмотреть.

> Черновик. Места в двойных квадратных скобках [[…]] заполняются после финальной сборки.

## 1. Что нужно

- Docker и Docker Compose (Docker Desktop на macOS / Windows или Docker Engine на Linux).
- Свободные порты: 5433 (база данных), 8080 (API), [[порт фронтенда]].
- Интернет при первом запуске (загрузка образов и внешних данных).
- Около [[N]] ГБ свободного места.

## 2. Запуск

```bash
git clone https://github.com/alieneth/tram-passenger-forecast.git
cd tram-passenger-forecast
cp .env.example .env
docker compose up -d
```

Первый запуск занимает около [[N]] минут: собираются образы, создаётся база данных, загружаются
готовые данные (справочник маршрутов, почасовой факт и прогноз на ноябрь–декабрь 2025).
Полный датасет (10 ГБ) для проверки не нужен.

Проверка, что всё работает:

```bash
curl http://localhost:8080/api/v1/health
```

Ответ `"status": "UP"` — сервис готов.

## 4. Что посмотреть за 5 минут

1. **Обзор** — прогноз на 14.11.2025 по всем маршрутам: карта и таблица «маршруты × часы», факторы дня.
2. **Маршрут** — выбрать маршрут: прогноз по часам с коридором уверенности, переход на неделю и месяц, вклад факторов.
3. **Карта** — «Проиграть день»: как меняется поток по маршрутам в течение суток.
4. **Что если** — изменить поправки на погоду, событие, сезон и увидеть пересчёт прогноза.
5. **Решения** — предложения по перераспределению трамваев при превышении нормы.
6. **Качество модели** — ошибка нашей модели и базовой на сентябре–октябре 2025.
7. **Экспорт** — выгрузка прогноза в CSV / XLSX и в формате сабмита.

## 5. Примеры запросов к API

```bash
# Список маршрутов
curl http://localhost:8080/api/v1/routes

# Прогноз маршрута 17 на 14.11.2025 по часам
curl "http://localhost:8080/api/v1/forecast?route=17&date_from=2025-11-14&horizon=day"

# Прогноз по дням на ноябрь
curl "http://localhost:8080/api/v1/forecast?route=17&date_from=2025-11-01&date_to=2025-11-30&horizon=month"
```

Все методы, параметры и коды ошибок — в Swagger и `docs/openapi.yaml`.

## 6. Если что-то не запустилось

| Симптом | Что сделать |
|---|---|
| Порт занят | Поменять порт в `.env` и перезапустить `docker compose up -d` |
| `/health` отвечает `DOWN` | База ещё стартует — подождать минуту; логи: `docker compose logs db` |
| `/health` отвечает `DEGRADED` | Прогноз ещё не загружен — [[команда загрузки прогноза]] |
| Нужна полная загрузка датасета | Положить CSV в `data/` и выполнить `docker compose run --rm loader` |
