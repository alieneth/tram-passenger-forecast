# frontend — дашборд (Сергей)

React 19, TypeScript 5 (strict), Prettier + ESLint, карта — MapLibre или Leaflet. См. раздел 11 в `/CLAUDE.md`.

Что здесь будет (волна MVP):

- каркас: меню, шапка, переключатель «День | Месяц»;
- экраны Обзор, Карта, Маршрут, Месяц, Экспорт;
- типы API — в `src/api/types.ts`, поля как в `docs/openapi.yaml` (`snake_case`);
- мок-данные — в `src/mocks/` строго в формате контракта;
- адрес API — из переменной окружения.

Общие правила интерфейса: только маршруты 1, 5, 7, 11, 12, 17, 25, 26, 28, 50; часы 05…23, 00; единицы — пассажиров в час / на трамвай (процентов нет); у маршрута 5 метка «новый · прогноз по аналогам».
