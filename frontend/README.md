# frontend — дашборд (Сергей)

React 19, TypeScript 5 (strict), Vite, Prettier + ESLint, TanStack Query, React Router, карта — MapLibre GL, графики — Recharts. См. раздел 11 в `/CLAUDE.md`.

## Запуск

```bash
npm install
npm run dev          # http://localhost:5173
```

Переменные окружения — в `frontend/.env.local` (пример — [`.env.example`](.env.example), сам файл в git не попадает).

**Моки или реальный API — решает `VITE_API_URL`:**

- не задан или пустой — фронт работает на мок-данных из `src/mocks/` (в шапке значок «Мок-данные»);
- задан — все запросы идут в API. Для локальной работы создай `frontend/.env.local` (в git не попадает):

```bash
VITE_API_URL=http://localhost:8080/api/v1
```

**Подложка карты — `VITE_MAP_STYLE_URL`** (стиль MapLibre, например тёмный CARTO из `.env.example`).
Не задана или нет интернета — карта рисуется на однотонном тёмном фоне, маршруты видны всё равно.

## Карта (UI-3)

- Цвет маршрута — **пассажиров на трамвай относительно нормы 150** (`PASSENGERS_PER_TRAM_NORM`):
  зелёный — до 80% нормы, жёлтый — 80–100%, красный — выше нормы, серый — трамваи не ходят. Один цвет на маршрут целиком.
- На экране «Карта» цвет — по выбранному часу шкалы (05 … 23, 00), «▶ Проиграть день» идёт по часам.
- На «Обзоре» маршрут красится по своему самому загруженному часу — поэтому красных маршрутов
  столько же, сколько в карточке «Маршрутов с пиковой нагрузкой» (с учётом списка «без координат»).
- Маршрут 5 — пунктир и метка «новый». Маршруты без координат (17, 25, 26, 28, 50) — списком под картой.
- Слой «Станции метро и МЦК» выключен: в контракте API нет метода со станциями.

## Маршрут (UI-4)

- «Дни × часы» и график дня строятся из одного запроса `GET /forecast` за месяц (горизонт `day`).
- Порог нормы на графике — `150 × trams_on_line` в пассажирах в час; участок выше порога — красный.
- «Неделю назад»: до 31.10 — факт (`GET /actuals`), позже — прогноз.
- Тип дня (выходной, праздник, перенос) — из `GET /factors` по каждой дате месяца.
- Блок «Показатели маршрута» ждёт метод API-7 — в контракте его пока нет.

## Месяц (UI-5)

- Горизонт «Месяц» на экране «Маршрут»: календарь месяца, график «Пассажиров в день», факторы месяца.
- Прогноз по дням — `GET /forecast?horizon=month` за ноябрь–декабрь (61 день, в пределах 62 по контракту);
  факт — `GET /actuals?granularity=day` за сентябрь–октябрь.
- Цвет клетки — от самого тихого дня месяца к самому загруженному. Клик по дню открывает его прогноз по часам.
- Погода месяца подписана: «прогноз погоды» или «климатическая норма» (без утечки из будущего).
- Обзор и Карта работают по часам одного дня — на «Месяце» они предлагают переключиться на «День».

## Команды

| Команда                           | Что делает                                                    |
| --------------------------------- | ------------------------------------------------------------- |
| `npm run dev`                     | Dev-сервер                                                    |
| `npm run build`                   | Проверка типов + сборка в `dist/`                             |
| `npm run lint`                    | ESLint (в т. ч. запрет `console`)                             |
| `npm run format` / `format:check` | Prettier                                                      |
| `npm run api:types`               | Перегенерировать `src/api/types.ts` из `../docs/openapi.yaml` |
| `npm run mocks:generate`          | Перегенерировать мок-прогноз `src/mocks/data/forecastDay.ts`  |

Перед коммитом: `npm run format && npm run lint && npm run build`.

## Структура

```
src/
├── api/            ← единственная точка доступа к данным
│   ├── types.ts    ← сгенерирован из docs/openapi.yaml — руками не править
│   ├── client.ts   ← getRoutes, getRouteGeometry, getForecast, getActuals, getFactors, exportForecast
│   ├── http.ts     ← fetch, параметры route=1&route=7, скачивание файлов
│   ├── errors.ts   ← ApiError: code + message из ответа API
│   └── config.ts   ← VITE_API_URL → мок-режим или API
├── mocks/          ← мок-«сервер»: те же ответы и ошибки, что в контракте
│   ├── handlers.ts
│   └── data/       ← маршруты, трассы, факторы, прогноз на 14.11.2025
├── config/         ← константы (норма 150, часы 05…00) и меню
├── context/, hooks/← фильтры шапки (День | Месяц, дата), запросы к API
├── components/     ← каркас, состояния (загрузка / пусто / ошибка), общие элементы
│   └── map/        ← карта MapLibre, шкала времени, слои, легенда
└── pages/          ← экраны
```

## Мок-данные

Строго по схемам `docs/openapi.yaml` (TypeScript проверяет каждый объект). Прогноз и факт считает
детерминированный генератор `src/mocks/data/forecast.ts` — одни и те же даты дают одни и те же числа.

- 10 маршрутов: 1, 5, 7, 11, 12, 17, 25, 26, 28, 50; маршрут 5 — `is_new: true`, прогноз `is_analog: true` с широким коридором, факта нет;
- трассы есть у 1, 5, 7, 11, 12 (координаты, кроме первых двух остановок маршрута 1, **условные**); для 17, 25, 26, 28, 50 — `404 GEOMETRY_NOT_FOUND`;
- прогноз «День» на 01.11–31.12.2025: 10 × 61 день × 24 часа = 14 640 строк (как `test_submission.csv`); «Месяц» — суммы по дням; строки маршрута 17 на 14.11 в 7 и 8 часов — точно из примера контракта;
- в будни у 11, 12, 26 в пик больше 150 пассажиров на трамвай; в выходные и праздники — ровнее и ниже; спад в предновогоднюю неделю;
- факт (`GET /actuals`) — сентябрь–октябрь 2025;
- факторы дня на любую дату сентября–декабря; 14.11 — точный пример контракта; погода — прогноз до 16.11, дальше климатическая норма. Особые дни 2025 (1, 3, 4 ноября, 31 декабря) и каникулы — сверить с таблицей DATA-5;
- ошибки — как в контракте: 404 с текстами из каталога ошибок, 400 при периоде длиннее 62 (прогноз) / 92 (факт) дней.
