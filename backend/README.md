# backend — API (Артём)

Java 21, Spring Boot. Стиль — Google Java Style (Spotless), см. раздел 11 в `/CLAUDE.md`.

Что здесь будет:

- загрузка train/test в хранилище;
- REST API по контракту `docs/openapi.yaml` (префикс `/api/v1`, JSON-поля в `snake_case`);
- чтение готовых прогнозов из таблицы, которую заполняет `ml/` (модель из Java не вызывается);
- приём потоковых данных + скрипт-имитатор;
- единый формат ошибок с понятными сообщениями;
- нагрузочный тест: цель p95 < 300 мс, сотни RPS, контейнер 2–4 vCPU / 2–4 ГБ.

Сборка (Maven или Gradle) — на выбор Артёма.
